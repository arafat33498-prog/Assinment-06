🚀 DigiTools Platform
📌 Project Name

DigiTools Platform

📝 Description

DigiTools Platform is a modern web application that provides various digital tools like resume builder, AI writing assistant, and productivity features to help users work smarter and faster. It is designed with a clean UI and smooth user experience.

⚙️ Technologies Used

⚛️ React.js

🎨 Tailwind CSS

⚡ Vite

🌼 DaisyUI

🔗 JavaScript (ES6)

✨ Features
🔹 1. Modern UI Design

Clean and responsive design using Tailwind CSS and DaisyUI.

🔹 2. Dynamic Product Cards

Products are rendered dynamically using JSON data and React components.

🔹 3. Fast Performance

Built with Vite for lightning-fast development and optimized build.
